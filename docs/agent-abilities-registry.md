- **tool:video_analyze**: Video analysis would enable temporal media understanding, event extraction, summarization, and quality review that Charon currently cannot perform directly.
- **skill:computer-use**: Charon has browser automation but lacks a stated general desktop-control layer for native applications.
- **skill:email-inbox-triage**: Charon lacks a stated authenticated email connector and dedicated safety workflow for inbox-wide triage and drafting.
- **skill:himalaya**: A portable email transport integration would unlock inbox management and outbound communication beyond generic web automation.
- **skill:google-workspace**: A first-class authenticated Workspace connector would add broad communication, scheduling, document, and spreadsheet automation.
- **skill:teams-meeting-pipeline**: A durable authenticated Teams and Graph pipeline would add enterprise meeting ingestion, event subscriptions, and reliable replay semantics not currently stated.
- **skill:comfyui**: ComfyUI would provide a broad new multimodal-generation and workflow-automation category that Charon's listed tools do not currently expose.
- **skill:heartmula**: This would add native music synthesis, a substantial media-generation category not represented by Charon's current tools.
- **skill:agentmail**: A dedicated inbound and outbound email identity would enable autonomous communication workflows that Charon's current tools do not directly provide.
- **skill:clip**: This would add semantic image understanding and retrieval, a significant modality not represented by Charon's current tools.
- **skill:guidance**: Grammar-enforced generation would make tool calls and machine-consumed outputs substantially more reliable than prompt-only formatting.
- **skill:llama-cpp**: Local inference would add private, offline, and low-cost model execution independent of hosted model providers.
- **skill:outlines**: Schema-constrained decoding would materially improve dependable automation and structured interoperability.
- **skill:serving-llms-vllm**: This would let Charon deploy and operate scalable model endpoints rather than merely consume external models.
- **skill:llava**: It would add general image reasoning and dialogue, opening an important class of multimodal tasks.

- **command:/approve**: An explicit approval workflow would add an important safety boundary for privileged or destructive autonomous actions.
- **command:/deny**: Denial with feedback complements approval gating and allows safe correction of risky agent behavior.
- **command:/approvals**: Explicit persistent approval policies would materially improve safety, governance, and usability around Charon's powerful Bash and process tools.
- **command:/memory**: Although Charon has Recall, UserModel, and ProjectKnowledge, an approval gate for persistent writes would add important privacy and memory-governance controls.
